## 3. PyTorch logistic baseline

Fit logistic regression **in PyTorch**. Lab 1 used the book’s `Sequential` + `Sigmoid` + `BCELoss` on a toy example. This stone uses the numerically stabler wrapper: one linear layer, **logits**, `BCEWithLogitsLoss` (same $\hat y = \sigma(z)$).

Use the instructor table and the supplied `split` column. Fit on `train`. Report on `validation` (leave `test` alone).

``` python
import torch
from torch import nn

model = nn.Linear(n_features, 1)          # z = Wx + b
criterion = nn.BCEWithLogitsLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-3)

optimizer.zero_grad()
logits = model(x).squeeze(-1)             # (B,)
loss = criterion(logits, y)               # y in {0, 1}
loss.backward()
optimizer.step()
```

Do **not** use `sklearn.linear_model.LogisticRegression` for this stone. DATA 322 already did the closed-form / sklearn version; here the point is the training loop you will reuse for the MLP.
